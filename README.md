# CSCI 1420 — Machine Learning

My coursework for **CSCI 1420 Machine Learning** at Brown University, Spring 2026 (instructor: Stephen Bach).

The course covered the theory and practice of statistical machine learning, following *Understanding Machine Learning* by Shalev-Shwartz and Ben-David: empirical risk minimisation and PAC learning, perceptron and regression, the bias–complexity tradeoff, boosting and decision trees, VC dimension, Naive Bayes, SVMs and kernel methods, neural networks and backpropagation, and unsupervised learning (K-Means, expectation maximisation, PCA).
